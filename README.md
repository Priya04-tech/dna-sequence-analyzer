# Dna-sequence-analyzer
A lightweight Python utility for computational biology that parses FASTA/FASTQ files, calculates GC contents , analyzes, nucleotide frequencies, translates DNA sequence into amino acid proteins.

## 🚀 Features

- *FASTA/FASTQ Parser:* Easily read and parse sequence files.
- *GC Content Calculation:* Compute the percentage of Guanine and Cytosine in DNA sequences to estimate thermal stability and melting temperature.
- *Nucleotide Frequency Analysis:* Count individual occurrences of Adenine (A), Cytosine (C), Guanine (G), and Thymine (T).
- *Protein Translation:* Translate DNA sequences into corresponding amino acid chains.
